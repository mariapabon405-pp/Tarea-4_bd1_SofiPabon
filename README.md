## Descripción del Proyecto
En esta cuarta entrega se implementa la estructura física de la **Red Social Estudiantil Pascualina** en tres Sistemas de Gestión de Bases de Datos diferentes (**PostgreSQL 17**, **MySQL 9.0** y **SQLite 3**). Además, se incorpora el soporte de tipos de datos semiestructurados (NoSQL / JSON) para gestionar escenarios reales de Big Data e Internet de las Cosas (IoT).
